# AUTO-BOTIX Robotics Curriculum 🤖📚

Welcome to the official source code repository for the **AUTO-BOTIX Robotics Curriculum Book**. This repository contains all daily practicals and capstone project codes designed for hands-on learning with the AUTO-BOTIX development board and Arduino.

## ⚙️ Requirements

* **Board:** AUTO-BOTIX Young Engineer Board / Arduino Nano
* **Software:** Arduino IDE
* **Default Baud Rate:** 9600 baud

---

## 🚀 How to Use

1. Click on any Week folder above or from the file list on the left.
2. Open the desired Day folder and click on the `.ino` file.
3. Download or copy the code directly into your Arduino IDE and upload it to your board.
